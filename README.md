# Translation-Helper
A mod to assist with the translation of Hypnagogia: Boundless Dreams. BepInEx is required for this mode to work.

### Mod capabilities
The mod includes a configuration file located at BepInEx\config\TranslationHelper.cfg. Let’s go over all the settings in more detail:

+  ***lang***. Specifies the folder where the translation will be located. It is found at Hypnagogia Boundless Dreams\TranslationHelper\translation\{specified parameter}, and its structure is as follows:
```
└── 📁 TranslationHelper
    └── 📁 translation
        └── 📁 ru
            ├── 📁 dialogs
            │   └── 📄 {dialog files}
            └── 📁 textui
                └── 📄 textui.txt
```

+ ***characterSpacing***. The spacing between characters in dialogs. Can be negative.

+ ***characterFontSize***. The font size in dialogs.

+ ***characterAutoSize***. Enable or disable automatic adjustment of character size in dialogs. If there isn’t enough space in the text field, the character size will be automatically reduced.

+ ***customFontDialogs***. Replaces the default font with your own in dialogs. The font folder is located at TranslationHelper\font. Example: “umeboshi.ttf” (without quotes).

+ ***customFontTextUI***. Replaces the default font with your own in the interface text. The folder is located at TranslationHelper\font. Example: “umeboshi.ttf” without quotes. For each interface element, you must separately enable the font for it in the textui.txt file located at TranslationHelper\translation\{language name}\textui\textui.txt.

+ ***debugMode***. Enable or disable debug mode. Displays information about captured objects (dialogs, interface text) in the console.

+ ***dialogLog***. Enable or disable the display of information about captured dialogs in the console.

+ ***writeLogFile***. Enable or disable writing information about captured objects (dialogs, UI text) to a file. The log file will be created in the TranslationHelper\logs folder.

+ ***maxLogFiles***. The maximum number of log files; if the number exceeds the specified limit, the oldest file will be deleted. To remove this limit, set the value to -1.

+ ***createDialogFiles***. Enable or disable the creation of dialog files. All dialogs captured during gameplay will be saved in files ready for translation. The files will be created in the path TranslationHelper\dump\dialogs. It does not overwrite files that have already been created.

+ ***createTextUIFile***. Enable or disable the creation of a file containing the user interface text. Text fields captured during gameplay will be saved in the ***textui.txt*** file. The file will be created in the path TranslationHelper\dump\textui\textui.txt. It does not create duplicates, except in cases where their hashes match.

Example of an intercepted dialogue. You can change anything inside the blocks, for example: [title=Gogi_0_begin] Change here [title=Gogi_0_end]. Anything after that can be used as a comment.

```
Cave Dialogue MAIN

GOGI
[title=Gogi_0_begin]
???: Heehee, hi there! So <i>good</i> to see you again! You don't remember me? I'm your old pal, <color=#fcbe2b><b>Gogi</b>!</color>
“Gogi”: Well, have [jitter=5 angle=0]fuuunnn![/jitter]
[title=Gogi_0_end]
```

Example of intercepted interface text, file ***textui.txt***. Here is the text ***h y p n o g o g i a*** on the game’s title screen. Since each letter is a separate element, there are that many entries. You can change everything inside the curly braces; the parameters within the square brackets are explained below:

+ ***hash***. You shouldn’t change this—it’s automatically generated by the mod as a unique identifier.

+ ***auto_sizing***. Enables or disables automatic character resizing in dialogs. If there isn’t enough space in the text field, the character size will be automatically reduced.

+ ***font_size***. Font size.

+ ***char_spacing***. Spacing between letters.

+ ***custom_font***. Enables or disables the use of a custom font. This is helpful when the interface text uses a font that does not support Cyrillic characters.

### Hotkeys
This mod features only one hotkey, F7, which refreshes the contents of all textui — meaning you can edit the translation in the file and see the changes immediately in the game.

### Creating your own translation
If you wish to create your own translation from scratch, you can use the files located in the TranslationHelper\translation\original folder (which contains all dialogues and almost all the interface text I was able to capture), or enable ***createTextUIFile*** and ***createDialogsFiles*** in the mod settings to capture dialogues and interface text. Then, translate the files. Finally, you need to recreate the following file structure:

```
└── 📁 TranslationHelper
    └── 📁 translation
        └── 📁 {your language name}
            ├── 📁 dialogs
            │   └── 📄 {dialogs files}
            └── 📁 textui
                └── 📄 textui.txt
```

After that, simply change the ***lang*** parameter to your language name, and you're all set.
